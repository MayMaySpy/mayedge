# No app auth; loopback plus Tailscale

The process binds loopback. Remote use is Tailscale, not an application login. There is no session, token, or desk password. Kill, tickets, and algo start are reachable by anyone who can reach the bind.

A login would be a second identity next to the wallet keys and the Tailscale ACL. This is a personal desk, not a multi-user service. If the bind is ever opened past loopback without Tailscale, that is a hole, not a product.
