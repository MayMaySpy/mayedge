# An Idea is a note, not an order

The Ideas page writes only to the desk database. Its one path toward the venue is the Draft hand-off: it gives the desk a Draft, and the operator starts the Planner from the desk as they would from a Draft drawn by hand ([ADR 0018](0018-the-chart-drafts-a-planner.md)). No price on the page triggers anything. A "buy when it reaches the zone" would be a second way to place orders, with no Planner dialog in front of it, on a page that is not the desk. If that is ever wanted, it is a Trail entry or a Planner, started from the desk.
